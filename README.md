# كنعاني سبورت (Kanaani Sport)

تطبيق رياضة خفيف مبني على تطبيق كنعاني. بيدخل بنفس حسابات كنعاني، وبيعرض بس المحتوى اللي بتحدده لوحة التحكم
(كنعاني سبورت ← الترتيب والباقات ← «باقة للتطبيق كله»).

- الإعدادات: `ibo-app/brand.properties`
- الإصدار: ملف `VERSION`
- كل push على main بيبني ويوقّع وبينشر `Kanaani-Sport.apk` مع `update.json`.
- رابط التحميل الثابت: https://github.com/Emad1995kanaan/kanaani-sport/releases/latest/download/Kanaani-Sport.apk
